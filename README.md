# Commodore_-_VIC-10

Thumbnails for Commodore VIC-10 software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `vic10` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/), scaled to 4:3 (640x480): the snaps are taken at MAME's 418x235, which is wider than the picture on a TV.
